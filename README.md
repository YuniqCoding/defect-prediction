# 반도체 공정 데이터로 불량 조기 판별

공정 계측 기록을 분석해 불량 가능성이 높은 흐름을 미리 걸러내는 프로젝트입니다.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| `data/` | 원본 데이터 파일을 두는 곳. 여러 날 실습에서 공용으로 씁니다. |
| `day01/` | 1일차 작업 폴더. |
| `day01/lab01_review/` | 실습 1 결과물. pandas로 공정 표 데이터를 읽고 확인하는 복습 노트북과 연습용 csv. |
| `day01/lab02_workspace/` | 실습 2 결과물. 설치한 파이썬 환경이 제대로 도는지 확인하는 노트북. |
